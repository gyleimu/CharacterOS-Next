## Candidate Reuse Unit

Research representation `AppraisalInferenceCandidate` is exactly `relevance`, `goal_congruence`, `attribution`, `controllability`, `uncertainty`, `intensity`, `assessment_confidence`. The first six form the dimensions object in a proposal. No subject/event/evidence/transition/persistence fields enter the slot. `candidateFromRaw` uses the existing product closed parser and canonical validator, including range and enum checks, instead of a simplified evaluator.

## Trusted Metadata Rebinding

For every SHADOW second event, the original product adapter regenerates `schema_version`, `status`, `subject_id`, `factual_event_ref`, `context_projection_hash` and `evidence_refs` from the trusted second context. The frozen executor derives source Observation/payload/history grounding, state/repository/logical-time basis, proposal hash, transition/intent/appraisal IDs, canonical record, Learning binding and authority receipts independently. No first-event trusted proposal or receipt is copied.

## Shadow Method

CONTROL independently receives recorded B; SHADOW receives recorded A through the same product adapter. Both call `completePendingLifecycleWork`, executing the actual Appraisal validator and commit chain followed by AffectApplication. Each comparison has one second-event proposal delivery, no hidden model retry. The actual baseline always used independent A and B calls. No inference is called early.

## Isolation Method

S is captured at the actual B provider boundary, before B executes. Each branch independently JSON-deserializes the full image, rebuilds its repository, restores ingress/delivery ledgers and the authoritative canonical chain, and adopts the same pending REPLY work. Both pre-images must equal S exactly. Example S01: `sha256:25e307770d06fb4241f3c4e4a13c150d6e57df4294500dbed356e0d880bd3c90`.

No value or identity is normalized away in CONTROL versus SHADOW; only object key order is ignored. The separate original-runtime-versus-restored-CONTROL cross-check requires exact canonical snapshot/repository equality but records restored reservation-counter/derived receipt differences. Those exceptions do not apply between the comparison branches. Full images, branches and differences are in each `evidence/Sxx-state.json.gz`; an independent offline authority replay reproduced all five archives exactly.
