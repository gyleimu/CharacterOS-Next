# CharacterOS voice runtime — verified dependency set.

# Versions below are what was ACTUALLY installed and run on Windows 11 with an
# RTX 4060 Laptop (8 GB), Python 3.10.21. They are not a guess.
#
# This is CosyVoice's own requirements.txt with the Linux-only and
# training-only entries removed, plus the ASR stack. Install with:
#
#   python.exe -m pip install "setuptools==75.8.0" wheel
#   python.exe -m pip install --no-build-isolation "openai-whisper==20231117"
#   python.exe -m pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu121
#   python.exe -m pip install funasr sounddevice
#
# WHY setuptools IS PINNED FIRST: CosyVoice's import chain needs `pkg_resources`,
# which setuptools removed in v81. Installing the current setuptools breaks
# `import cosyvoice` and the openai-whisper wheel build.
#
# WHY openai-whisper IS BUILT WITHOUT ISOLATION: pip's isolated build
# environment pulls the current setuptools, so its setup.py fails on
# `import pkg_resources`. Building it against the pinned setuptools works.
#
# Dropped from CosyVoice's requirements.txt, deliberately:
#   * `deepspeed`, `tensorrt-*`, `onnxruntime-gpu` — marked Linux-only upstream.
#   * the `--extra-index-url` lines — passed on the command line instead, so the
#     Azure index (which returns 401) is not consulted on Windows.
